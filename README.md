# Adaptive Web Buddy Extension

A friendly popup that helps you quickly preview accessibility tweaks (text size, color palettes, reading modes) and a playful bye page.

## Installation

### Chrome / Edge
1. Open your browser and go to `chrome://extensions/` (or `edge://extensions/`)
2. Enable "Developer mode" (toggle in the top right)
3. Click "Load unpacked"
4. Select the `AWB` folder
5. The extension should now appear in your extensions list

### Firefox
1. Open Firefox and go to `about:debugging#/runtime/this-firefox`
2. Click "Load Temporary Add-on"
3. Select the `manifest.json` file from the `AWB` folder
4. The extension should now be loaded

## Usage

1. Click the extension icon in your browser toolbar to open the home popup.
2. Use the buttons to jump into focused tools:
   - **Text settings** – adjust the preview font size with Increase/Decrease/Reset.
   - **Color presets** – pick from light, dark, sepia, or calm blue palettes.
   - **Reading modes** – preview Focus, Dim, or Dyslexic-friendly layouts.
   - **Bye page** – switch between farewell messages or get a surprise.
3. Each tool page includes a "← Back" button to return to the main popup.
